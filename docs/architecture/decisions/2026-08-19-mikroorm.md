# Use MikroORM for persistence

| Field | Value |
| --- | --- |
| Status | Accepted |

## Context

Yetano Work is a PostgreSQL-backed business application whose domain will require relationships,
transaction boundaries, migrations, and consistent object identity during a request. Persistence
must fit TypeScript without requiring decorators or runtime reflection metadata.

## Decision

Use MikroORM with its PostgreSQL driver as the persistence layer. Follow the Data Mapper and Unit of
Work model, define entities with `defineEntity`, and keep decorators and `reflect-metadata` out of the
project.

Create a forked `EntityManager` for every request, bind it through MikroORM `RequestContext`, and
inject it into application services through the request-scoped Awilix container. Represent every
schema change with a committed MikroORM migration.

## Rationale

MikroORM's Data Mapper, Unit of Work, and identity map support a domain-oriented model while keeping
persistence concerns at explicit boundaries. Its request context and migration tooling match the
project's need for controlled transactions and consistent entity instances within one operation.

## Alternatives considered

- An Active Record model would couple persistence operations directly to domain entities and make
  service-level transaction boundaries less explicit.
- A SQL- or query-builder-first approach would provide lower-level control but require the project
  to build more identity, change-tracking, relationship, and migration conventions itself.

## Consequences

- Services that access the database must use the request-scoped `EntityManager`; sharing the root
  manager across requests is not allowed.
- Developers must understand Unit of Work flush and transaction semantics.
- Entity discovery and migrations become part of module implementation and verification.
- Database-backed behavior requires integration tests against PostgreSQL, not only mocked unit
  tests.
- Avoiding decorators keeps entity definitions explicit but may differ from common MikroORM
  examples.
